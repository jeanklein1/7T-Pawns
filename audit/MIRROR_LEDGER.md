## The coverage target

Five relations. A mirror fact is COVERED if one of these columns
holds it; everything else is residue.

| relation | key | columns |
|---|---|---|
| `SLOTS` | (group, binding) | symbol, aliases, namespace, kind, address space, accesses, store type, runtime-array flag, texture sample/format/dimension |
| `SEATS` | (layout, entry index) | slot ref, visibility, hasDynamicOffset |
| `LAYOUTS` | layout | state.hpp member, label, accessor |
| `GROUPS` | bind group | layout ref, label, per-seat backing resource member |
| `PIPELINES` | pipeline | ordered layout list, entry points, vertex buffers/attributes |

pipelines) and is not duplicated here — one fact, one home. What this
ledger adds is the GROUPS backing column (M6), the idiom shapes the
generator must emit (M1), the scatter it must respect (M2), and the
